# Design System Tokens · Fideliz-Ar PWA Cliente

## Filosofía
- Minimalismo oscuro (Dark Mode nativo).
- Modularización en bloques Lego.
- Cero código espagueti, cero código zombie.
- Arquitectura móvil orientada a billetera de tarjetas (Wallet / Apple Style).

## Tokens Fundacionales

### Colores
- **Background Principal:** `#09090b` (Zinc 950 / Black)
- **Superficie Cards:** `#18181b` (Zinc 900)
- **Bordes:** `#27272a` (Zinc 800)
- **Texto Principal:** `#fafafa` (Zinc 50)
- **Texto Secundario:** `#a1a1aa` (Zinc 400)
- **Acento Primario (Oro/Premio):** `#eab308` (Yellow 500) / `#facc15` (Yellow 400)

### Tipografía
- **Familia:** `Plus Jakarta Sans`, `Inter`, system-ui
- **Escala:**
  - `text-xs`: 12px (labels, estados)
  - `text-sm`: 14px (metadatos, subtítulos)
  - `text-base`: 16px (cuerpo, botones)
  - `text-lg`: 18px (títulos de tarjetas)
  - `text-xl`: 20px (encabezados)

### Radios & Sombras
- **Card Radius:** `rounded-2xl` (16px) o `rounded-3xl` (24px)
- **Badge Radius:** `rounded-full`
- **Sombra Card:** `shadow-lg shadow-black/40`
